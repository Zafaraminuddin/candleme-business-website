# CandleMe Business Website

Working website for the CandleMe business and salon pilot experience.

## Pages

- `index.html` - Main CandleMe business page
- `salon.html` - Salon program page
- `professional.html` - Individual professional page
- `why-candleme.html` - Why CandleMe
- `start-a-pilot.html` - Pilot setup page

## Current purpose

This repository is the live review and iteration environment before the website is moved to Google Cloud for production integration.

## Publishing

The site is designed to publish directly from the repository root through GitHub Pages. All images required by the current review version are embedded in the HTML files.
